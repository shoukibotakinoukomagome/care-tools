# care-tools

介護記録ツール（データは端末内にのみ保存されます）

## album/
日常の様子アルバム（25枚版）。写真は端末内で縮小して埋め込み、「保存」で完成HTMLを端末にダウンロード。サーバーには何も送らない。
https://shoukibotakinoukomagome.github.io/care-tools/album/

## album16/
日常の様子アルバム（4×4＝16枚・横写真は自動で横長枠）。album20/ と同内容。
https://shoukibotakinoukomagome.github.io/care-tools/album16/

## album20/
日常の様子アルバム（4×4＝16枚・横写真は自動で横長枠・見出し/一言欄/枠線/PDF印刷）。album16/ と同内容（アイコン名違い）。
https://shoukibotakinoukomagome.github.io/care-tools/album20/

## biyori/
こまごめ日和（広報紙・A4表裏）の編集ページ。年と月を選ぶと見出し・色・飾りが切り替わる。写真枠は縦長中心で、小さい横長を少しまぜた（大きい枠は横長）。号ごとに端末内に保存。iPadはホーム画面に追加して使う（「PDFをつくる」→「保存・印刷する」で共有シート）。サーバーには何も送らない。
https://shoukibotakinoukomagome.github.io/care-tools/biyori/

## keirou2/
敬老の日の写真フレーム（2人用・海の絵・丸8個・A4横2枚）。左右のお名前と日付は入力欄から入れる（絵には名前を描いていない）。途中の状態は端末内に自動保存。1人用の keirou/ とは別のアプリ（保存も別）。iPadはホーム画面に追加して使う。サーバーには何も送らない。
https://shoukibotakinoukomagome.github.io/care-tools/keirou2/
